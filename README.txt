MZArch — Responsive Website Prototype

Файлы:
- index.html — вся структура сайта
- styles.css — адаптивный дизайн
- script.js — мобильное меню и демонстрационная форма

Как открыть:
1. Распакуйте архив.
2. Откройте index.html в браузере.

Что уже реализовано:
- Mobile-first адаптация
- Версии для телефона, планшета и компьютера
- Главная, проекты, услуги, о себе, процесс, контакты
- Мобильное полноэкранное меню
- Цвета: белый, черный, красный
- Основные SEO-теги
- Простая форма заявки

Важно:
- Фотографии пока загружаются с Unsplash как временные изображения.
- Телефон, email, Instagram, статистика и тексты нужно заменить на реальные.
- Для публикации можно использовать обычный хостинг, Netlify, Vercel или GitHub Pages.
